# Easy Save Image / Easy Image Metadata

두 노드는 모든 ComfyUI 확산 모델 워크플로우에서 사용할 수 있으며 EasyUse의
자체 이미지 저장 엔진을 사용합니다. ComfyUI-Image-Saver가 필요하지 않습니다.

최종 `IMAGE`를 **Easy 이미지 저장**에 연결하고 출력 하위 폴더, 확장자를 제외한
파일 이름, PNG/JPG/JPEG/WebP 형식과 압축 설정을 선택합니다. `품질`은 JPEG/WebP에
적용되며 PNG는 무손실입니다. `WebP 무손실`은 무손실 압축을 사용하고 `PNG 최적화`는
저장 시간을 더 사용해 파일 크기를 줄입니다. 기존 이미지와 워크플로우 JSON은
번호를 붙여 보존합니다. 저장 폴더는 ComfyUI의 출력 폴더 안에 있어야 합니다.

생성 정보를 포함하려면 같은 최종 `IMAGE`를 **Easy 이미지 메타데이터**에도 연결합니다.
긍정·부정 프롬프트, 모델 이름, 시드, 스텝, CFG, 샘플러, 스케줄러, 디노이즈와
필요한 CLIP 스킵·추가 텍스트를 입력하고 `EXIF 메타데이터` 출력을 저장 노드에 연결합니다.
크기는 최종 이미지에서 읽습니다. `생성 파라미터` 텍스트 출력으로 A1111 형식의
결과를 확인할 수도 있습니다. 로컬 모델 해시는 ComfyUI 모델 목록 안에서만 조회하고
Civitai 통신이나 모델 로딩은 하지 않습니다. 샘플링 설정은 입력한 값을 기록하며
이미지 픽셀에서 추론하지 않습니다.
메타데이터 시드는 입력한 값을 그대로 기록하며 저장 후 자동 변경하지 않습니다.

PNG에는 `parameters` 텍스트, JPEG/WebP에는 EXIF `UserComment`를 기록합니다.
**Easy 이미지 저장**의 `워크플로우 포함`은 저장 실행의 ComfyUI 프롬프트와 워크플로우를 포함하고,
`워크플로우 JSON 저장`은 같은 이름의 JSON 파일을 만듭니다. JPEG의 워크플로우가
EXIF 용량을 넘으면 별도 JSON으로 저장하므로 해당 JSON을 열어 복원하세요.
두 옵션은 EXIF 소켓 연결 여부와 독립적으로 동작합니다. 픽셀만 저장하려면 소켓을
연결하지 않고 두 옵션을 모두 끄세요. Easy 이미지 메타데이터의 출력은 A1111 생성
정보만 보관하며 워크플로우 데이터와 저장 옵션은 포함하지 않습니다. 저장 노드의
워크플로우 옵션을 바꿔도 상위 메타데이터 노드의 입력은 바뀌지 않습니다.
ComfyUI의 `disable_metadata`
설정은 캐시된 메타데이터를 포함해 모든 메타데이터와 JSON 저장을 막고 해시 계산도 건너뜁니다.

이전 개발 버전의 워크플로우는 열 때 메타데이터 노드의 저장 옵션을 연결된 저장 노드로
이전합니다. 이전에 소켓을 연결하지 않은 저장 노드는 두 옵션을 끈 상태를 유지합니다.
새 저장 노드는 워크플로우 포함이 켜지고 JSON 저장은 꺼진 상태로 생성됩니다.
기존 API 프롬프트에서는 두 옵션을 저장 노드 입력으로 옮겨야 합니다.

**Easy Civitai 조회**에 모델 파일 해시 또는 버전이 포함된 Civitai AIR를 입력합니다.
AIR 예시는 `urn:air:sd1:checkpoint:civitai:4384@128713`입니다. AutoV3·SHA256 해시,
AIR, 모델·버전 이름, 트리거 단어와 `추가 해시`를 출력합니다. `추가 해시` 출력을
Easy 이미지 메타데이터의 같은 이름 소켓에 연결하면 A1111 데이터에 리소스 해시를
포함합니다. `가중치`는 A1111 텍스트의 `Resource weights` JSON 필드에 기록되므로
워크플로우를 포함하지 않아도 이미지에서 확인할 수 있습니다. 이미지나 모델 파일은 다운로드하지
않으며 필요한 텍스트만 제한된 캐시에 보관합니다. 조회 실패 시 잘못된 해시 대신 오류를 알립니다.

조회는 Civitai의 [모델 버전 API](https://developer.civitai.com/site/reference)를 사용합니다.

기존 AiO 저장 설정과 노드 식별자는 유지됩니다. 공유하는 경로·파일 저장·메타데이터
제한은 [자체 저장 엔진 계약](../architecture/native-image-output.md)에 설명되어 있습니다.
