# 0.2.4 Development Notes

## Scope

0.2.4 is a hotfix release for a post-0.2.3 AiO image-save regression.
The release keeps the 0.2.3 runtime behavior and narrows the change to
best-effort Civitai metadata handling in the AiO Image Saver integration.

## Fixed

- `Anima AiO Generator` no longer fails a completed image save when
  `Civitai Hash Fetcher (Image Saver)` returns an API error such as HTTP 503,
  returns no usable hash, or raises a temporary upstream exception.
- The failed Civitai hash entry is skipped and a warning is logged; existing
  manual `additional_hashes`, hash bundles, and successful Civitai hashes are
  still passed to Image Saver.
- Missing local configuration, such as a Civitai Hash Fetcher row with only
  one of `username` or `model_name`, remains a clear runtime error.

## Changed

- Package metadata is set to `0.2.4`.
- The release also includes documentation commits made after the `v0.2.3` tag:
  refreshed EasyUseAnima guides, README demo videos, and expanded ANIMA Easy
  Use workflow documentation.

## Review Notes

- The upstream Image Saver Civitai metadata path is best-effort: invalid manual
  hashes and missing Civitai metadata are logged or skipped while saving
  continues.
- The only EasyUseAnima path found that converted upstream Civitai fetcher
  `Error:`/`No ...` string results into a fatal exception was
  `_aio_image_saver_civitai_hash_fetcher_entries`.
- Other checked runtime errors in this area are still required-output or
  required-configuration failures, not optional metadata lookups.
