# 0.5.4 Development Notes

## Scope

0.5.4 is the patch release for the Wildcard, Prompt Studio, and AiO fixes
integrated on `dev` after 0.5.3. It preserves the existing public node,
workflow, settings, profile, and API contracts.

## User-Visible Changes

- The standalone Anima Wildcard node again exposes Normal, Fixed, Sequential,
  and Reproduce modes. Mode and deterministic seed behavior survive workflow
  save, load, and queueing.
- Prompt Studio resolution buckets include exact 2:3 and 3:2 choices at the
  512, 768, 896, 1024, and 1536 tiers without removing existing choices.
- AiO optional-dependency notices no longer appear during ordinary load or
  queue paths. A notice appears only when the user explicitly selects an
  unavailable feature.
- AiO profile save no longer relies on the browser-native `prompt()` API, which
  is unsupported in ComfyUI Desktop. Nested profile and dependency dialogs stay
  above the AiO settings window.

## Package Contract

- Package version: `0.5.4`
- Plain-text Registry changelog:
  `.github/registry/changelogs/0.5.4.txt`
- Maintained release workflow metadata: `package_version=0.5.4`
- Registry 0.5.3 remains immutable and is marked deprecated only after 0.5.4
  is available.

## Validation

- The exact release candidate passed the official full project runner: 733
  Python unittests, 114 frontend JavaScript smoke files, TypeScript 6.0.3, and
  diff checks.
- Registry validation uses `comfy node validate` and a pre-publish
  `comfy node pack` archive inspection.
- Focused regression coverage includes standalone Wildcard mode persistence,
  exact 2:3 and 3:2 resolution buckets, explicit-only dependency notices, and
  Promise-safe AiO profile dialog behavior.
- The final AiO profile save/list/delete and missing-dependency dialog layering
  were checked in the ComfyUI 0.27.0 Node 2.0 interface before this metadata
  slice.

## Release And Rollback

- Release target: protected `dev` to `main` PR followed by annotated tag
  `v0.5.4`.
- Publish only after the tag resolves to the released `main` commit.
- If a release fix is needed, publish a later patch version. Never replace the
  0.5.4 Registry payload or rewrite its public tag.
