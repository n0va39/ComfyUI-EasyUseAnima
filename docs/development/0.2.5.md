# 0.2.5 Development Notes

## Scope

0.2.5 is the next planned patch version after the tagged 0.2.4 hotfix.
The release scope covers Prompt Studio text rendering cleanup, AiO preview
handling fixes, prompt translation marker support, and English ANIMA Easy Use
workflow documentation.

## Current Changes

- Package metadata is set to `0.2.5` as the next-version marker.
- Prompt Studio text areas use the system UI font and root font size by default
  instead of a fixed 12px monospace font in the Advanced editor.
- Prompt Studio highlight overlays re-copy input text metrics after settings
  changes, so the input text and overlay stay aligned.
- A manual Prompt Studio font correction setting is available for display
  mismatch cases only:
  - `prompt_studio.font_override`
  - `prompt_studio.font_family`
  - `prompt_studio.font_size`
- The manual font family and size values are registered in backend defaults,
  Comfy settings key mapping, frontend settings UI, and regression tests.
- AiO Generator now renders Comfy denoising latent previews inside its own image
  preview panel when the frontend receives metadata-backed preview events.
- AiO Generator suppresses duplicate Comfy native preview overlays while keeping
  the EasyUse Anima preview panel active.
- Prompt translation marker support is available in Prompt Studio and
  autocomplete flows through the prompt translation runtime helper and settings.
- English ANIMA Easy Use workflow documentation is available alongside the
  Korean guide.

## Release Follow-Up

- Confirm the default system-font path visually in a live ComfyUI instance when

- Confirm AiO denoising preview rendering visually in a live ComfyUI instance
