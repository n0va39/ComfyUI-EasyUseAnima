# 0.3.0 Development Notes

## Scope

0.3.0 is the next Registry-facing release after the 0.2.x line. This file
tracks the release-prep cleanup, validation scope, and remaining publish
checks.

## Current Changes

- GitHub Actions can update Comfy Registry metadata and already-published
  version changelogs without publishing a new package version.
- Future Registry publishes should provide an explicit release changelog through
  the Comfy CLI publish path.
- Registry scanner safety rules are now documented in
  `docs/development/registry-scanner-safety.md`.
- Runtime scanner-trigger surfaces were reduced before the 0.3.0 release prep:
  optional SAM3/Impact imports are static, prompt translation defaults to off,
  API-key environment auto-detection was removed, and NAIA remote hosts require
  an explicit allow setting.
- `.comfyignore` now excludes development-only docs, tests, CI metadata,
  workflow samples, generated media, logs, caches, and other non-runtime files
  from Registry archives while keeping root README files available.
- Tests remain repository validation assets and are not packaged into Registry
  archives.
- Public node registration no longer exposes standalone `Anima SAM3 Context` or
  `Anima SAM3 Detailer` nodes.
- AiO Generator's internal SAM3 detailer path remains available through AiO
  Detailer settings.
- User-facing README and node guide entry points no longer link standalone SAM3
  node pages.
- AiO Generator Image Saver metadata now uses Prompt Studio metadata prompt
  outputs when they are available, without changing generation or Mod Guidance
  prompt inputs.
- AiO release workflows now ship with conservative optimization defaults:
  FP16 accumulation off, SageAttention disabled, Sage compile disabled, and
  TorchCompile off. The v6 workflow guide markdown documents that these options
  should be enabled only after confirming the local PyTorch/CUDA/Triton stack.

## Release Follow-Up

- `pyproject.toml` is bumped to `0.3.0` for release prep.
- `RELEASE.md` includes the final 0.3.0 notes from the actual post-0.2.7
  change set.
- Run Registry preflight, including Comfy CLI validation, before Registry
  publishing.
- Confirm scanner grep output has no high-risk runtime patterns except the
  documented localhost-default NAIA `requests.post`.
- Publish via the manual GitHub Actions flow with a changelog file.
