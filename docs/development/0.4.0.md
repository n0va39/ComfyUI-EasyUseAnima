# 0.4.0 Development Notes

## Scope

0.4.0 is the first feature release after 0.3.2. It adds complete AiO generation
profiles and ships the Node 2.0/legacy canvas resize and wheel ownership fixes
developed after the 0.3.2 tag.

## User-Visible Changes

- Added `Normal`, `Turbo`, and `Optimized` AiO generation profiles.
- Added named user profiles stored in ComfyUI user data.
- Added exact `Custom` state detection for settings that do not match a
  built-in profile or that were edited after applying a user profile.
- Added clear available/missing/query-failed reporting for AiO optional
  dependencies.
- Stabilized Prompt Studio Advanced text wrapping and height recalculation
  after width changes.
- Stabilized Prompt Studio Advanced and AiO Generator node resize behavior on
  Node 2.0 and legacy canvas.
- Made existing editor/panel scrollbars consume wheel input even at their
  boundaries, while preserving canvas zoom when no scrollbar exists.
- Kept AiO final images in ComfyUI queue/history while suppressing the
  duplicate legacy canvas label.

## Compatibility

- Built-in profile application replaces the complete AiO generation settings.
- Existing workflows keep their serialized generation settings. Settings that
  do not exactly match a built-in profile are displayed as `Custom`.
- Named user profiles are installation-local. Workflows serialize settings
  rather than the selected user profile name.
- Hidden `generation_settings` serialization and queue input contracts remain
  unchanged.
- Node 2.0 and legacy canvas remain supported frontend surfaces.
