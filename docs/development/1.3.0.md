## 목표와 현재 경계

AiO가 사용하는 외부 노드 중 작은 기능을 직접 유지하여 설치·업데이트 상태에 따른
호환성 부담을 줄인다. DAVE와 Safe PAG를 우선 후보로 삼고, 현재 유지관리 활동이
확인되는 Spectrum은 부분 통합의 타당성을 먼저 조사한다. 최근 commit 공백만으로
upstream의 지원 중단을 단정하지 않는다.

현재 외부 호출에는 Spectrum sampler/forecast/correction/Anima Mod Guidance,
KJ compile/Sage/FP16, DAVE, Safe PAG, ppm NegPip, Impact Detailer/MaskToSEGS,
USDU가 있다. native Image Saver는 이미 자체 출력 경로이며 SAM3 detector와
기본 loader·샘플러는 ComfyUI core 경계다.

DAVE와 Safe PAG는 각각 독립 PR과 rollback 단위를 가진다. #768은 내장 전환 시
UI 안내와 Python 실행부의 의존성 판정이 어긋나지 않도록 함께 검토하되, 모든
작업의 선행 조건으로 만들지는 않는다. 실제 method/signature/출력 검사는 해당
adapter에 남기며 범용 동적 import·실행 dispatcher를 도입하지 않는다.

관련 구조 제안 [#769 — Python 분석 기준의 구조 계약과 소스 지문 분리](https://github.com/n0va39/ComfyUI-EasyUseAnima/issues/769)는
별도로 검토한다. 실제 수정 diff로 검토 비용과 보호 계약을 비교한 뒤 계약 PR을
먼저 제안하며, 완료된 backend 모듈 이동을 다시 시작하거나 기존 검증을 완화하는
작업으로 해석하지 않는다.

## 채택 조건과 통합 정책의 적용

사용자의 장기 통합 요청과 #764에서 정한 후보 검토·구현은
[외부 노드 구현 복사 금지 기본 원칙](custom-node-integrations.md#integration-rules)의
작업별 예외 범위다. 아래 조건을 충족한 작은 구현에 한해 해당 이슈에서 채택을
진행한다. 전체 pack의 일괄 복사나 미확인 자산의 재배포로 범위를 확대하지 않는다.

1. 채택 파일마다 원 저장소, 고정 commit, 원본 경로·hash, 적용 라이선스와 변경
   내용을 기록한다. 코드와 upstream 파생 코드, mask·calibration·모델 weights의
   권리는 각각 확인한다. 공개 저장소이거나 root LICENSE가 있다는 사실만으로
   모든 포함 자산의 조건을 확정하지 않는다.
2. DAVE는 [MIT 원문 @83143e8](https://github.com/sorryhyun/ComfyUI-Anima-DAVE/blob/83143e8d84768e25f72755ec00ea00ded07ee06e/LICENSE)과
   `dave_alpha.npz`의 출처·권리를 대조한다. Safe PAG는
   [MIT 원문 @905b010](https://github.com/iljung1106/comfyui-anima-safe-pag/blob/905b0107d1f924fc6acbcac3b6a879b566ff671c/LICENSE)의
   이름 없는 저작권 문구도 그대로 보존하고 출처·기여 이력을 별도로 기록한다.
3. 원저작 고지·라이선스와 필요한 수정 고지가 Registry package 및 수동 설치 ZIP에
   포함돼야 한다. 문서 폴더에만 두어 실제 배포에서 빠지지 않도록 확인한다.
4. 기존 node ID, workflow/profile, JSON key·값, stage scope, seed·sampler,
   MODEL/CLIP/conditioning 계약을 보존한다. 기존 외부 pack과 함께 설치해도
   이중 patch가 없어야 하며 선택하지 않은 기능은 새 의존성·다운로드를 요구하지 않는다.
5. 고정 upstream과의 수치·동작 비교 및 최신 안정 ComfyUI 호환 검증을 완료한다.
   권리·출처·자산 또는 호환성이 미확정인 부분은 이슈에 조건을 남기고 기존 adapter를
   유지한다.

Spectrum은 [root MIT @1925664](https://github.com/sorryhyun/ComfyUI-Spectrum-KSampler/blob/192566487d0d9cdbd892e464eedd53c4efa972c2/LICENSE)와
별개로 vendor의 원 출처, 상위
[anima_lora NOTICE](https://github.com/sorryhyun/anima_lora/blob/135b976c223071c1c7851039dfbcf3565639a659/NOTICE),
ComfyUI core를 반영한 코드, 기본 adapter·calibration 자산의 조건을 #767에서 대조한다.

KJNodes·Impact·USDU의 GPLv3 및 ppm의 AGPL-3.0-or-later 구현은 통합 결과에 적용될
라이선스·배포 조건을 먼저 결정해야 한다. 이번 DAVE/Safe PAG 예외를 이들 구현의
복사·MIT 재표시로 확대하지 않는다. Impact Detailer/MaskToSEGS는 현재 위임 경계를
유지한다.

ResShift는 [#679](https://github.com/n0va39/ComfyUI-EasyUseAnima/issues/679)의 안전한
loader 작업과 비상업 조건을 연결해 추적한다. CC BY-NC-SA와 S-Lab vendor·weights
조건은 loader 안전성과 별개이며, 현재 실행 차단과 저장 설정 호환을 유지한다.

## 구현 검증과 완료 판정

- DAVE: `model_patches.dave`, mask 선택, Compile→DAVE 순서, sigma/step gate,
  stage 제외·zero strength의 identity, 28/40-block 경계와 성공·실패·중단 후
  hook/wrapper 해제를 확인한다.
- Safe PAG: `model_patches.safe_pag`, stage scope, 기존 sampler callbacks,
  공유 attention 객체와 부분 patch 실패를 포함한 `compute_attention` 원래 reference
  복구를 확인한다. 다음 generation과 sibling stage에 변경이 남지 않아야 한다.
- 공통: 기존 focused 계약·fixture를 재사용하고 외부 pack 부재/동시 설치,
  disabled 경로, profile·workflow 복원을 검사한다. #768에서는 조회 전·조회 실패·
  missing의 현재 구분도 보존한다.
- 최종 코드 후보에서 changed-file 검사와 직접 focused check, `git diff --check`,
  workspace의 `tools/check_custom_node.ps1 -Project <worktree> -Profile full`을
  수행한다. 유효한 동일 코드·환경 증거는 재사용한다.
- 내장 구현의 host 경계는 격리된 `ComfyUI_codex_test`를 공식 최신 안정 릴리즈로
  갱신한 환경에서 GPU smoke로 확인한다. 갱신·dependency sync 실패는 환경 실패로
  기록한다. UI·serialization 변경은 Legacy Canvas와 Node 2.0을 각각 검증한다.
- 채택 코드·고지·자산의 package 포함 여부를 확인하고, 구현 PR과 증거를 owning
  Issue에 연결한 뒤에만 해당 항목을 완료로 바꾼다.

이 계획 문서만 바꾸는 DOC 작업은 diff·링크 검사로 확인하며 full/runtime을 새로
실행하지 않는다. 현재 오류 수정 #760–#763 및 #772의 완료를 위 기능·구조 계획의 구현 완료로
계산하지 않는다.
