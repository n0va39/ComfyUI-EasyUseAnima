# 0.5.2 Development Notes

## Scope

0.5.2 is the patch release for the completed frontend maintenance Goal. It
contains bug fixes and compatibility refactoring already integrated on `dev`;
it does not add a new feature track or change public node, workflow, or API
contracts.

## User-Visible Changes

- Autocomplete supports up to 100 suggestions, preserves surrounding nested
  prompt syntax during replacement, and reconnects after reloads and delayed
  Legacy text-field mounting.
- AiO Generator keeps concurrent direct queue seeds distinct, keeps preview
  wheel input local, exposes the Detailer threshold, and preserves live resource
  and Detailer choices.
- LoRA Preset has stable profile save/reload data and correct Node 2.0 profile
  list wheel ownership and redraw.

## Package Contract

- Package version: `0.5.2`
- Plain-text Registry changelog:
  `.github/registry/changelogs/0.5.2.txt`
- Maintained release workflow metadata: `package_version=0.5.2`
- Registry 0.5.1 remains an immutable published version. Its current Flagged
  status is the known informational NAIA network-request scanner finding and
  requires external review; it is not overwritten or reused.

## Validation

- Exact final production `dev` checkpoint: Python unittest 412/412, 110
  frontend JavaScript files, TypeScript 6.0.3, and diff checks.
- Shared backend evidence: one successful AiO queue completed a 512x512 first
  pass and 2x USDU output at 1024x1024.
- Difference surfaces were checked separately: Legacy delayed DOM attachment
  and final ComfyUI 0.27.0 compatibility; Node 2.0 LoRA wheel hit testing and
  redraw; dual-canvas save/reload evidence for the relevant AiO and LoRA
  changes.
- Release preparation is metadata, workflow metadata, documentation, and
  release-copy regression coverage only. Production browser and GPU validation
  is not repeated unless the production tree changes.
- An actual committed `comfy node pack` archive contained 144 entries, package
  version 0.5.2, and the complete tracked Autocomplete runtime surface (7/7).

## Included Maintenance Range

- Post-0.5.1 maintenance PRs #131 through #150, excluding documentation-only
  checkpoints from the user-visible change list.
- Completed Issues #54, #55, #56, #62, #66, #98, and #100.
- Issue #111 remains an upstream-facing, non-blocking Node 2.0 display mismatch
  and is not worked around with private DOM code in this release.

## Release And Rollback

- Release target: protected `dev` to `main` PR followed by annotated tag
  `v0.5.2`.
- Publish only after the tag resolves to the released `main` commit and the
  GitHub Release asset is verified.
- If a release fix is needed, publish a later patch version. Never replace the
  0.5.2 Registry payload or rewrite its public tag.
