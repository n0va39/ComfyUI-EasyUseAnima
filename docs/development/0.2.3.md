# 0.2.3 Development Notes

## Scope

0.2.3 is a targeted release for regressions found after the 0.2.2 AiO release.
The release keeps the 0.2.2 AiO runtime design and focuses on frontend
autocomplete, Prompt Studio highlighting, AiO Detailer/Highres blocker fixes,
and refreshed release workflow metadata.

## Fixed

- `Anima AiO Generator` Detailer Settings popup renders Face/Eye detailer blocks
  again after opening the popup.
- Detailer Settings can add, save, reorder, and run custom detailer blocks while
  preserving the built-in Face/Eye blocks.
- Highres Settings saves the Highres Spectrum/DCW optimization section instead
  of resetting those values on apply.
- Highres and Detailer stages keep Spectrum/DCW settings stage-specific even
  when CFG, sampler, and scheduler follow the main sampler.
- Autocomplete without inline preview keeps broad search behavior while preview
  mode remains strict to prefix-compatible completions.
- Korean autocomplete queries update during IME composition instead of waiting
  for a space, refocus, or caret click.
- Korean description/keyword searches such as `하츠네 미쿠` keep the matched tag
  suggestion in inline preview filtering.
- Arrow-key movement in the autocomplete popup scrolls the active row into view
  while keeping one adjacent row visible above and below when possible.
- Wildcard autocomplete opens for empty `__`, accepts Korean wildcard keys, and
  searches normalized space, underscore, and slash variants.
- Prompt Studio wildcard highlighting accepts Unicode wildcard keys and keeps
  wildcard/dynamic prompt syntax color ahead of unknown-token highlighting.
- Backend prompt classification marks wildcard syntax and dynamic prompts,
  including comma-containing dynamic prompts such as `{1-3$$, $$red|blue}`, as
  the wildcard section.

## Changed

- Package metadata is set to `0.2.3`.
- Maintained release workflow JSON files carry `0.2.3` package metadata.
- Bundled Korean AiO release workflow JSON files were refreshed with current
  embedded workflow defaults.
