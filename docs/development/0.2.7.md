# 0.2.7 Development Notes

## Scope

0.2.7 is the next planned patch version after the tagged 0.2.6 release. The
release scope includes frontend reliability and maintainability fixes that
landed after `v0.2.6`, including autocomplete stability and Node 2.0 / legacy
canvas DOM widget compatibility work.

## Current Changes

- Package metadata is set to `0.2.7` as the next-version marker because
  `0.2.6` has already been released.
- Global autocomplete attachment is restored for ComfyUI Nodes 2.0 prompt text
  fields that appear or re-render after the EasyUse Anima extension initially
  loads.
- Autocomplete query parsing now strips prompt syntax before search, including
  escaped literal parentheses such as `\(blue archive\)`, while preserving the
  original prompt syntax for insertion behavior.
- Autocomplete popup scroll reset now runs after the popup is visible and again
  on the next animation frame, so a newly rendered suggestion list starts from
  the top even after the previous list was scrolled.
- The autocomplete popup disables scroll anchoring to prevent browser scroll
  restoration from carrying stale offsets into new result sets.
- Prompt Studio frontend code is split into responsibility-based
  `web/js/prompt_studio/*.js` modules with a no-build JS typecheck gate.
- Prompt Studio Advanced and Advanced v2 keep node resize, editor viewport, and
  textarea height ownership separate for Node 2.0 and legacy canvas.
- `Anima AiO Generator` maps user node height to the internal panel viewport so
  settings and preview areas grow and shrink with the node instead of leaving a
  blank node body.
- Advanced editor wheel forwarding keeps wheel events inside native controls
  only while those controls can scroll; otherwise canvas zoom/pan remains
  available.
- Advanced editor CSS no longer reserves an empty scrollbar gutter when the
  editor does not need to scroll.

## Patch Contents

- `web/js/easyuse_anima_autocomplete.js`
  - Node 2.0/global autocomplete hook stabilization.
  - Prompt-syntax-aware autocomplete search query normalization.
  - Popup scroll reset timing and scroll anchoring fix.
- `web/js/easyuse_anima_prompt_studio.js`
  - Thin Prompt Studio extension entry that delegates behavior to
    `prompt_studio` modules.
- `web/js/prompt_studio/*.js`
  - Prompt Studio module split for layout, schema, serialization, controls,
    textarea handling, wheel forwarding, style injection, hooks, and state.
- `web/js/easyuse_anima_aio.js`
  - AiO DOM panel viewport sizing aligned with user node height.
- `tests/test_aio_frontend.py`
  - Source guards for global hook state, query parsing, popup scroll reset
    ordering, and AiO DOM viewport height behavior.
- `tests/test_frontend_modules.py`
  - Source guards for Prompt Studio module boundaries, layout ownership,
    serialization ownership, wheel forwarding policy, typecheck scope, and
    import-cycle prevention.
- `tests/test_prompt_corrector.py`
  - Regression coverage for escaped literal parenthesis search.

## Release Follow-Up

- Confirm live ComfyUI 0.25.x autocomplete behavior after a browser hard
  refresh:
  - `\(blue archive\)` should find tags such as `asuna \(blue archive\)`.
  - Opening a different suggestion list after scrolling a long list should
    start from the top.
- Confirm live ComfyUI 0.25.x DOM widget behavior after a browser hard refresh:
  - `Anima AiO Generator` vertical resize should resize its internal
    settings/preview panel without leaving blank node body space.
  - `Anima Prompt Studio Advanced v2` should not reserve a scrollbar lane when
    the editor does not need to scroll.
  - Wheel over a non-scrollable Advanced textarea should still allow canvas
    zoom/pan; wheel over a scrollable textarea should scroll the textarea.
- No ComfyUI restart is required for the frontend JavaScript changes, but a
  browser hard refresh may be needed.
